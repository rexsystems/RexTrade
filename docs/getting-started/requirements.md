---
title: Requirements
description: Java 21 and Paper 1.21 or newer.
sidebar:
  order: 2
---

- Java 21
- Paper, Purpur, or Folia 1.21+
- Vault, when a currency uses `type: vault`
- PlaceholderAPI, when a currency uses `type: placeholder`

The plugin declares `folia-supported: true`. Inventory checks and item returns run on the player's region scheduler. Currency commands run on the global region scheduler.
