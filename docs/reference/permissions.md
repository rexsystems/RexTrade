---
title: Permissions
description: Who can trade and who can reload.
sidebar:
  order: 2
---

| Permission | Default | Description |
|---|---|---|
| `rextrade.use` | true | Send a request, accept one, deny one, cancel, and set an offer |
| `rextrade.reload` | op | Reload `config.yml` |

A shift-right-click without `rextrade.use` is not cancelled. The click passes through.
